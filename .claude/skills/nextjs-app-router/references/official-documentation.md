# Next.js App Router Official Documentation and Standards

## App Router Overview

### What is the App Router?
The App Router is Next.js's new routing system that provides:
- File-based routing system
- Built-in conventions for layouts, nested routing, and more
- Server Components by default
- Streaming and Suspense integration
- Colocation of components, styles, and tests

### Key Concepts
- **Routes**: Defined by folders in the `app` directory
- **Pages**: Rendered at specific routes using `page.js` files
- **Layouts**: Shared UI between routes using `layout.js` files
- **Templates**: New instances of UI for each route
- **Loading UI**: Loading states using `loading.js` files
- **Error Boundaries**: Error handling using `error.js` files
- **Nested Routes**: Hierarchical route structures

## Directory Structure

### Basic App Router Structure
```
app/
├── layout.js          # Root layout
├── page.js           # Home page (/)
├── about/
│   ├── page.js      # About page (/about)
│   └── layout.js    # Layout for /about and subroutes
├── dashboard/
│   ├── page.js      # Dashboard page (/dashboard)
│   ├── settings/
│   │   └── page.js  # Settings page (/dashboard/settings)
│   └── layout.js    # Layout for /dashboard and subroutes
└── globals.css      # Global styles
```

### Advanced Structure with Route Groups
```
app/
├── (marketing)/       # Route group for marketing pages
│   ├── layout.js
│   ├── page.js      # /
│   ├── about/
│   │   └── page.js  # /about
├── (dashboard)/     # Route group for dashboard
│   ├── layout.js
│   ├── dashboard/
│   │   ├── page.js  # /dashboard
│   │   └── settings/
│   │       └── page.js  # /dashboard/settings
├── (auth)/          # Route group for auth pages
│   ├── login/
│   │   └── page.js  # /login
│   └── signup/
│       └── page.js  # /signup
└── layout.js        # Root layout
```

## Server vs Client Components

### Server Components (Default)
```javascript
// app/products/[id]/page.js
import { getProduct } from '@/lib/products'

// This runs on the server
export default async function ProductPage({ params }) {
  const product = await getProduct(params.id)

  return (
    <div>
      <h1>{product.name}</h1>
      <p>{product.description}</p>
    </div>
  )
}
```

### Client Components
```javascript
// app/counter.js
'use client'

import { useState } from 'react'

// This runs on the client
export default function Counter() {
  const [count, setCount] = useState(0)

  return (
    <div>
      <p>Count: {count}</p>
      <button onClick={() => setCount(count + 1)}>
        Increment
      </button>
    </div>
  )
}
```

### When to Use Each
- **Server Components**: Data fetching, security-sensitive operations, SEO-critical content
- **Client Components**: Interactive UI, browser APIs, event handlers

## Data Fetching Patterns

### Server Component Data Fetching
```javascript
// Data fetching in server components is cached by default
async function getData() {
  const res = await fetch('https://api.example.com/data')
  return res.json()
}

export default async function Page({ searchParams }) {
  const data = await getData()

  return <div>{/* Render data */}</div>
}
```

### Dynamic Data Fetching
```javascript
// Disable caching
async function getData() {
  const res = await fetch('https://api.example.com/data', {
    cache: 'no-store'  // Always fetch fresh
  })
  return res.json()
}

// Revalidate data
async function getFreshData() {
  const res = await fetch('https://api.example.com/data', {
    next: { revalidate: 3600 }  // Revalidate every hour
  })
  return res.json()
}
```

### Streaming with Suspense
```javascript
// app/page.js
import Products from './products'
import Reviews from './reviews'

export default function Page() {
  return (
    <div>
      <Products />
      <Suspense fallback={<ReviewsSkeleton />}>
        <Reviews />
      </Suspense>
    </div>
  )
}

// app/reviews.js
import { getReviews } from '@/lib/reviews'

export default async function Reviews() {
  const reviews = await getReviews()

  return (
    <div>
      {reviews.map(review => (
        <div key={review.id}>{review.content}</div>
      ))}
    </div>
  )
}
```

## Layout and Template Patterns

### Root Layout
```javascript
// app/layout.js
import './globals.css'

export const metadata = {
  title: 'My App',
  description: 'Generated by create next app'
}

export default function RootLayout({ children }) {
  return (
    <html lang="en">
      <body>{children}</body>
    </html>
  )
}
```

### Nested Layouts
```javascript
// app/dashboard/layout.js
export default function DashboardLayout({ children }) {
  return (
    <section>
      <nav>Dashboard Navigation</nav>
      <div>
        {children}
      </div>
    </section>
  )
}
```

### Template vs Layout
- **Layout**: UI that persists across route changes (shared state, effects)
- **Template**: New instance for each route (animations, unique state)

```javascript
// Using templates for animations
export default function DashboardLayout({ children }) {
  return (
    <section>
      <Template>
        <nav>Dashboard Navigation</nav>
        <div>{children}</div>
      </Template>
    </section>
  )
}
```

```javascript

  return (

    </div>
  )
```


## Parallel and Intercepting Routes

### Parallel Routes
```javascript
// app/@analytics/page.js
export default function Analytics() {
  return <div>Analytics Panel</div>
}

// app/@editor/page.js
export default function Editor() {
  return <div>Editor Panel</div>
}

// app/layout.js
export default function Layout({
  children,
  analytics,
  editor
}) {
  return (
    <>
      {children}
      {analytics}
      {editor}
    </>
  )
}
```

### Intercepting Routes
```javascript
// app/feed/@modal/(..)photo/[id]/page.js
// Intercepts app/photo/[id] and renders in modal
export default function PhotoModal({ params }) {
  return (
    <div className="modal">
      <Photo id={params.id} />
    </div>
  )
}
```

## Advanced Patterns

### Route Handlers
```javascript
// app/api/users/route.js
import { NextResponse } from 'next/server'

export async function GET() {
  const users = await getUsers()
  return NextResponse.json(users)
}

export async function POST(request) {
  const body = await request.json()
  const user = await createUser(body)
  return NextResponse.json(user, { status: 201 })
}
```

### Middleware
```javascript
// middleware.js
export function middleware(request) {
  // Protect routes
  if (request.nextUrl.pathname.startsWith('/dashboard')) {
    const token = request.cookies.get('token')
    if (!token) {
      return Response.redirect(new URL('/login', request.url))
    }
  }
}

export const config = {
  matcher: ['/dashboard/:path*', '/admin/:path*']
}
```

```javascript
export default function Page() {

    <Image
      src="/me.png"
      alt="Picture of the author"
      width={500}

      priority
    />

```

### Font Optimization
```javascript
// app/layout.js
import { Inter } from 'next/font/google'

const inter = Inter({ subsets: ['latin'] })

export default function RootLayout({ children }) {
  return (
    <html lang="en" className={inter.className}>
      <body>{children}</body>
    </html>
  )
}
```

### Link Prefetching
```javascript
import Link from 'next/link'

export default function Navigation() {
  return (
    <nav>
      <Link href="/about" prefetch={false}>About</Link>
      {/* prefetch: false disables automatic prefetching */}
    </nav>
  )
}
```

## Internationalization

### Locale Structure
```
app/
├── layout.js
├── page.js              # Default route
├── en/
│   ├── layout.js
│   └── page.js
├── fr/
│   ├── layout.js
│   └── page.js
└── [...locale]/
    ├── layout.js
    ├── page.js
    └── about/
        └── page.js
```

### Configuration
```javascript
// next.config.js
/** @type {import('next').NextConfig} */
const nextConfig = {
  i18n: {
    locales: ['en', 'fr', 'es'],
    defaultLocale: 'en',
  },
}

module.exports = nextConfig
```
